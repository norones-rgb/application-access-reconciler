# Roadmap

These are future enhancements, not implemented features.

| Priority | Enhancement | Acceptance criteria |
| --- | --- | --- |
| 1 | Approved exceptions | Owner, justification, scope, and expiry; expired exceptions return to the queue |
| 2 | Export provenance | Source timestamps, hashes, row counts, and completeness checks stored with the assessment |
| 3 | Review decisions | Record reviewer, decision, evidence, and completion time without altering the original finding |
| 4 | License analysis | Vendor-specific billing model and measured eligible seats; distinguish potential from realized savings |
| 5 | Non-human identities | Separate inventory and ownership model for bots, service accounts, and shared accounts |
| 6 | Connector adapters | Read-only SaaS adapters with documented scopes, pagination, retry handling, and synthetic test fixtures |

## Potential follow-on portfolio projects

- A contract-aware Jira and Confluence license analyzer using synthetic usage exports.
- A service request dashboard covering volume, backlog aging, access request categories, and SLA performance using synthetic ticket exports.

Keep each project small enough to explain and maintain. Add working features and verified screenshots before making résumé claims.
