# Publish and present the repository

Suggested repository name: `application-access-reconciler`

Suggested description: Read-only Python reconciliation for employee identities and SaaS application accounts, with access-review findings and HTML, CSV, and JSON reports.

Suggested topics: `identity-access-management`, `python`, `access-review`, `saas`, `license-management`, `cybersecurity`, `portfolio`.

## Before publishing

Run the sample assessment and tests. Read the rules and practice the demonstration in `docs/DEMO.md`. The included source, sample data, and demo reports are intended for a public portfolio. Do not substitute employer code or actual company exports.

## Upload through GitHub

1. Sign in and create a new repository with the suggested name and description.
2. Choose Public if you want hiring teams to inspect it without requesting access.
3. Leave the generated README and license options off; this folder already contains both.
4. Upload the contents of this project folder, preserving the `access_reconciler`, `sample_data`, `tests`, `docs`, and `demo_output` directories. Upload extracted files, not the ZIP itself.
5. Open the repository README and verify that its relative links work. Pin the repository on your profile.

You can also initialize and publish with your preferred Git client. No remote URL is preconfigured in this package.
